## 1. Що таке immutable об’єкт? Для чого об’єкти класу String зробили імутабельними? Чому клас String задекларований як final?

**Immutable об'єкт** (незмінний об'єкт) — це об'єкт, стан якого не можна змінити після створення. У Java об'єкти класу `String` є імутабельними, що означає, що будь-яка операція над ними, яка вимагає зміни їхнього стану, створює новий об'єкт, а не модифікує існуючий.

**Чому `String` є імутабельним**:
- **Безпека**: Оскільки строки часто використовуються як параметри для мережевих з'єднань, доступу до файлів тощо, їхня незмінність захищає від несанкціонованої зміни під час передачі.
- **Оптимізація продуктивності**: Імутабельність дозволяє Java використовувати пул строк (String pool), де повторювані значення можуть бути збережені й використані без дублювання в пам’яті.
- **Потокобезпека**: Імутабельні об'єкти автоматично є потокобезпечними, тому `String` можна безпечно використовувати в багатопотокових середовищах без синхронізації.

**Чому клас `String` задекларований як final**:
- Це забезпечує неможливість успадкування і, відповідно, змін структури класу `String`, що гарантує його імутабельність.

## 2. Що таке регулярні вирази? Наведіть приклади регулярних виразів.

**Регулярні вирази** — це шаблони, які використовуються для пошуку та маніпуляцій зі строками. Вони допомагають знаходити рядки, які відповідають певному шаблону, або ж виконувати заміну.

**Приклади регулярних виразів**:
- `\\d+` — знаходить одну або більше цифр.
- `[A-Za-z]+` — знаходить слова, що складаються тільки з літер.
- `^\\s+|\\s+$` — знаходить пробіли на початку або в кінці рядка.
- `\\b\\w{5}\\b` — знаходить слова з рівно п'яти букв.
- `[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\\.[A-Za-z]{2,}` — знаходить електронні адреси.

## 3. В чому полягає різниця між оператором «==» та методом «equals()»?

- **Оператор `==`** порівнює посилання на об'єкти, перевіряючи, чи вказують вони на ту саму ділянку пам'яті.
- **Метод `equals()`** порівнює сам зміст об'єктів, що дозволяє визначити, чи є їхні значення ідентичними.

Наприклад, для `String str1 = new String("hello")` і `String str2 = new String("hello")`:
- `str1 == str2` поверне `false`, оскільки `str1` та `str2` — це різні об'єкти в пам'яті.
- `str1.equals(str2)` поверне `true`, оскільки значення обох строк однакове.

## 4. Для чого потрібні класи StringBuilder та StringBuffer?

Класи **`StringBuilder`** та **`StringBuffer`** дозволяють створювати змінювані (mutable) строки, що корисно при необхідності частих змін тексту. Вони використовуються для оптимізації роботи з текстом, наприклад, коли необхідно динамічно додавати чи видаляти символи.

- **StringBuilder** — не синхронізований, підходить для використання в однопотоковому середовищі, швидший за `StringBuffer`.
- **StringBuffer** — синхронізований, підходить для багатопотокового середовища, де потрібен доступ до строк з кількох потоків.
